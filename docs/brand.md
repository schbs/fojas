# Identidad visual: Estudio Ruca & Asociados (marca ficticia)

Asistente que responde solo desde los documentos del estudio, citando documento y página. Estética editorial sobria
(lo pide el goal). Pie obligatorio: "Proyecto de demostración — marca ficticia". Skill `design-identity-per-client`.

## Brief
- **Rubro:** estudio contable chico de Neuquén. **Público:** clientes monotributistas, pymes y empleadores.
- **3 adjetivos:** confiable, preciso, tranquilo.
- **Gustan:** expedientes bien ordenados, notas al margen de un libro, señalética de archivo.
- **No gusta:** chatbots con burbujas de colores y robots sonrientes.
- **Conversión:** que la persona encuentre la respuesta con su fuente, o sepa que la deriva un contador.

## Tres direcciones

| | A · Expediente (recomendada) | B · Archivo | C · Boletín |
|---|---|---|---|
| Concepto | Cada respuesta es una foja: texto sobrio y la cita al margen, como en un expediente | Los documentos como fichas de un archivo con pestañas | Las respuestas con la autoridad de una circular impresa |
| Display / texto | Newsreader / Public Sans | Libre Caslon Text / Work Sans | Spectral / Karla |
| Primario / acento | azul acero `oklch(0.38 0.06 235)` / lacre `oklch(0.50 0.15 30)` (solo sellos) | ciruela `oklch(0.40 0.10 330)` / papel `oklch(0.95 0.02 85)` | ocre `oklch(0.55 0.11 70)` / tinta `oklch(0.25 0.02 260)` |
| Layout | Columna de lectura angosta + margen derecho para las citas | Grilla de fichas con pestañas por documento | Dos columnas tipo boletín, número de circular grande |
| Movimiento | La cita se resalta al pasar por la frase que respalda (opacity) | La pestaña sube al abrir la ficha (transform) | Subrayado que se dibuja bajo la fuente |
| Forma | Sin radios, reglas finas, papel blanco cálido | Esquinas de 2 px, pestañas | Filetes dobles, mucho blanco |
| Gesto propio | El sello de cita "Doc · p. 2" en el margen, como foliado | La pestaña con el código del documento (RUCA-CIR-03) | El número de circular como titular |

**Elegida: A · Expediente** (Germán, 31/10/2026: "hacé lo que recomiendes"). Es la que mejor muestra lo que el proyecto
vende (cada afirmación con su fuente al lado) y la más distinta de Embudo. En P2-G3 se fijan los tokens y se mide el
contraste AA.
